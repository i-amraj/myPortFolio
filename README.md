## 💻 Local Development

Clone and preview the portfolio locally with any static web server:

```bash
# 1. Clone the repository
git clone https://github.com/i-amraj/myPortFolio.git

# 2. Navigate to directory
cd myPortFolio

# 3. Serve using Python or VS Code Live Server
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
